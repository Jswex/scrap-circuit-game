# Entrepreneurship Game

## Purpose

Build and test a game concept for an entrepreneurship class. The project will treat the game as both a playable product and a way to validate a business hypothesis with prospective players or customers.

No genre, platform, or game engine has been selected yet.

## Current Status

The first playable vertical slice, **Scrap Circuit**, is implemented as a dependency-free browser game. It includes a three-lap race, three bot opponents, collectible upgrades, position tracking, touch controls, and a finish state.

Open `index.html` in a browser to play. Use WASD or the arrow keys to drive and Space to activate an upgrade.

For project history, read [`docs/BUILD_LOG.md`](docs/BUILD_LOG.md). If this is your first time working with coding agents, start with [`docs/AGENT_GUIDE.md`](docs/AGENT_GUIDE.md).

## First Session Checklist

- Define the target customer or player.
- Write the problem statement and riskiest business assumption.
- Choose one measurable learning goal for the first playtest.
- Sketch the smallest playable vertical slice.
- Compare suitable engines or libraries against the slice's needs.
- Record decisions and class requirements in `docs/`.

## Project Layout

- `docs/`: hypotheses, research, playtest notes, decisions, and class deliverables
- `src/`: game source code
- `assets/`: project-owned visual, audio, and data assets
- `tests/`: automated tests and test fixtures
